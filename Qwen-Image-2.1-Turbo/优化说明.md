# 适配说明与优化边界

首版保持 checkpoint BF16 参数、结构、tokenizer、CPU 随机数生成器和内置 8 步采样语义，不进行量化或减少计算步数。

1. Python 3.10 与现有 DTK Torch 保持不变。Diffusers 固定到兼容 Python 3.10 且包含采样 sigmas 支持的上游提交，Transformers 和 tokenizers 安装到隔离目录。
2. SGLang 0.5.18 使用 `--backend diffusers`，调用原始 `QwenImage21Pipeline`；不声明其为 SGLang 原生融合算子实现。
3. SGLang 旧注册路径与新版 Transformers 内置 `qwen3_asr` 重名。在模型服务进程内保留内置注册，其他模型注册仍委托原函数。
4. SGLang 的旧 RoPE 参数兼容补丁会跳过缺少文本位置字段的视觉配置。仅对 `Qwen3VLVisionConfig` 恢复 Transformers 原始标准化方法，保持视觉 axial RoPE 配置；不手工改 checkpoint。导入前后完整配置对照保存在 `results/config-probe-fixed/config-comparison.json`。
5. 通用 Diffusers 后端默认只读取第一张条件图。在本模型服务进程内保留全部条件图列表，沿用相同 RGB 加载函数，再交由官方 pipeline 预处理；当前实测两图，不声明四图均已验证。
6. 拒绝非有限输出，禁止静默修复 NaN/Inf 后宣称成功。功能检查保留原始接口响应、图像、逐像素哈希、实际请求配置及原生日程证据。

以上属于首版适配，不声明相对首版的优化收益。后续优化版需使用同卡、同框架、同精度、同输入及相同卸载策略配对测量，并回归正式图像指标。
