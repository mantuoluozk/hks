# Qwen3-ASR-1.7B 精度基线与评测口径

2026-10-25 查阅发布者 [QwenLM/Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR)，固定源码版本 `7c6daf77a2421100f5fb066495372c00129d39ff`，文本快照及 SHA256 见 `sources/`。

发布者 README Evaluation 表中，1.7B 的 LibriSpeech test-clean/test-other WER 为 **1.63 / 3.38**。评测使用 BF16、vLLM、greedy、最大生成 1024 token，不指定语种。这里是发布者的全量基准分数，并非本机测得的结果。

赛事 T04 要求音频到文本且包含流式，使用公示子集的 WER/CER，较官方 GPU 基线劣化 ≤2%。需要同时拿到对应子集、归一化/打分脚本和 GPU 基线，不能把任意小样本与发布者全量分数直接比较并判为达标，也不把 ≤2% 自行解释为 2 个绝对百分点。

工程验证分别记录：聊天音频输入、转写接口、SSE 文本输出流式、PCM 分块输入流式、并发与 RTF。两个官方演示音频用于功能检查；其转写非空、语言正确或者两个接口一致，均不能替代 WER/CER 验收。音频数据仅在服务器保存，不上传数据集。
