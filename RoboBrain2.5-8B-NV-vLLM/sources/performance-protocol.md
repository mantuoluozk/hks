# 性能负载依据

依据项目保存的官方赛事详情2026-10-23版bench.sh及《国芯国模黑客松-技术报告模板》第7章。

- 输入长度参数4096/16384，固定输出1024，客户端并发1/8/64，共六档。
- 每档连续两轮，第一次预热，取第二次数据。
- 每轮请求数N=max(8,2×并发)，分别8/16/128。
- 多模态理解使用image数据，每请求带一张图片。
- 合计(8+16+128)×2种输入长度×2轮=608条矩阵请求；第二轮计分304条。
- 客户端内部试请求与功能请求另计。

608是依据官方参数计算的总量，并非另加的第二套完整矩阵。本轮只运行一个服务进程的完整矩阵，不将其写作两个独立进程复现。
