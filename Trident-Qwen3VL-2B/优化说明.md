# Trident BW 适配说明

使用 vLLM 既有 Qwen3-VL backbone 与通用 embedding adapter，运行时指定 `Qwen3VLForConditionalGeneration`、`runner=pooling`、`convert=embed`、`LAST` 和归一化激活。模型没有生成式输出；不修改权重、框架源码、视觉塔、tokenizer 或训练指令。

query / doc 指令、图像像素上限、assistant generation prefix 和最后有效 token 池化均对照发布者固定版本。参考实现 BF16 / SDPA 在同一 BW 上运行，逐向量、逐 token 与 native vLLM 比较。首版不声称量化或 kernel 优化收益。

首次性能采用独立图片 UUID 防止跨请求或同批次视觉编码结果复用，关闭 prefix cache 和预处理缓存。计时只累计同步 `llm.embed` 调用，输出审计在计时外；原先未显式隔离视觉缓存的探测保留为 preliminary cached probe，不用于首版基准与复跑比较。固定示例重复不等于独立样本，批次大小不等于 HTTP 并发。

当前不将 batch 档位之间的吞吐差当作 ≥10% 优化奖励结论。
