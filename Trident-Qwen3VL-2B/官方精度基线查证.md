# Trident-Qwen3VL-2B 公开精度参考

发布者论文：[Chaos in the Text: Revealing the Modality Preference in Mixed-Modality Retrievers](https://arxiv.org/abs/2610.11816v1)，第 8 页 Table 1。已核对 PDF 表头、模型行和列顺序：`Trident-Qwen3VL-2B (Ours)` 的 ChartQA **Origin NDCG@10 ×100 = 70.19**，**Mix = 65.82**。

Origin 使用各数据集独立的原始单模态候选库；Mix 使用六个视觉文档数据集混合后合并的候选库。不能用仅 ChartQA 的混合候选库对照论文 Mix 列。发布者仓库说明论文使用 8×A100-80GB，测试环境为 Python 3.12 / PyTorch 2.10 / Transformers 4.57.1；本适配实际环境在报告中另列。

评测脚本与处理规范固定在 [OpenBMB/Trident](https://github.com/OpenBMB/Trident/tree/7fbf4b2033e1b3a43a99185fc125d765a549c52d)。公开评测数据固定 `OpenBMB/Trident-Eval@15c41335843f8880e24778843b462234b6427e4f`，完整 ChartQA Origin 为 1,250 查询 / 1,509 图像候选；输出归一化向量，使用发布者原始打分代码计算检索指标。

论文值是发布者 GPU 参考，发布者实现与 vLLM 在同一 BW 上的数值对照属于实现一致性检查。赛事精度仍待公示检索指标、容差和验收代码，不将任一种自检冒充官方验收 PASS。
