查阅日期：2026-10-24。

官方论文：[RoboBrain 2.5: Depth in Sight, Time in Mind](https://arxiv.org/html/2601.14352v1)，第 6 节，表 2/3。以下只摘取 `RoboBrain-2.5 (8B) NV` 行，不能混用 MTT、4B、RoboBrain2.0 或基座 Qwen3-VL 成绩。

这是发布者公开成绩的索引，不是本机成绩，也不是赛事正式 baseline 文件。复测前必须核对数据版本、拆分、评测器、提示、图像处理、坐标空间及生成参数。不能直接对任意自建子集套用上述全量分数并计算 PASS。

赛事最新 T02 描述将具身模型限定为 serving 适配，机器人任务不在范围；验收明确要求在公示图像（含深度图）输入集上，解析后的动作/坐标与 GPU 参考输出一致率 ≥98%，且单图/多图正常。因此，本模型首先需要对应输入集与逐例 GPU 参考输出。论文中的空间基准成绩可以作为补充公开自评，不能替代这项一致率验收；Smoke 里的坐标格式合法也不等于坐标准确或 ≥98% 一致。

当前：`official_accuracy_pass=null`，尚未执行官方精度验收。已完成本机固定例的图执行前后逐字对比、重复动作稳定性，以及 4 路并发下 24 个动作响应与串行输出的对比；这些不能填入官方 GPU 一致率分数。


## 2026-10-26 公开输入、参考输出与赛事验收包复查

本轮检索了赛事全名/T02/GPU 参考相关关键词，并检查发布者 GitHub、Hugging Face 模型文件列表，以及关联 RoboTracer、Robo-Dopamine 项目。未找到可确认属于本赛事、匹配 RoboBrain2.5-8B-NV checkpoint 的完整“固定输入集 + 逐例 GPU 输出 + 比较脚本/容差”包；这不等于证明未公开或未在参赛群发放。赛事飞书详情与 SCNet 模型动态页无法通过本轮网页读取工具直接读取，不能用公开搜索覆盖情况替代对这些页面和群附件的核验。

- [RoboBrain 2.5 官方代码](https://github.com/FlagOpen/RoboBrain2.5)：有 demo 图片、提示和统一推理入口；示例输入不等于赛事指定输入，未发现对应赛事逐例 GPU 参考输出。
- [模型文件列表](https://huggingface.co/BAAI/RoboBrain2.5-8B-NV/tree/main)：公开可列举的文件为权重、模型/处理器/tokenizer 配置及 README，没有列出赛事 GPU reference 结果文件；下载内容访问条件以发布者当前页面为准。
- [TraceSpatial-Bench](https://huggingface.co/datasets/JingkunAn/TraceSpatial-Bench)：可见 100 条样本，含 prompt、RGB image、depth、gt_depth、trajectory、相机内参及几何标注。它能提供公开自评输入和标注；标注轨迹不是 RoboBrain2.5-8B-NV 的 NVIDIA 推理输出。
- [RoboTracer 评测代码](https://github.com/Zhoues/RoboTracer/tree/main/Evaluation)：提供 test_benchmark.py 和 summarize_acc.py 等工具。
- [RoboTracer 已发布输出](https://github.com/Zhoues/RoboTracer/tree/main/Evaluation/outputs)：本轮可见 Gemini3Pro 与 RoboTracer_Intrinsics_Depth 的 2D/3D JSONL；不是本次 RoboBrain2.5-8B-NV checkpoint 的逐例参考，不能替换。
- [Robo-Dopamine](https://robo-dopamine.github.io/)：有时序价值估计相关 benchmark 入口，与本赛事动作/坐标逐例一致率不是同一协议。

应向赛事方确认：T02 固定图像/深度图输入集、逐例 GPU 参考输出、动作/坐标解析与比较脚本、坐标系/单位/容差，以及是否允许参赛者用同一 checkpoint 在 NVIDIA GPU 自行生成对照。自行生成的结果须标为自建 GPU 对照；只有赛事方认可对应输入与协议后，才用于其正式一致率验收。
