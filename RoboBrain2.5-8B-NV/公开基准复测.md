## CV-Bench 协议

- 数据：[nyu-visionx/CV-Bench](https://huggingface.co/datasets/nyu-visionx/CV-Bench)，固定 revision `bc284db50d036958861cb60cdd7b77612052ce0d`；完整 test 共 2,638 题，含 2D 1,438 题及 3D 1,200 题。
- 评测框架固定 revision：`fef27ec696c532d12f0db389bcbbf79eab0e4c41`。任务配置为 `tasks/cv_bench/cv_bench_test.py`；程序直接加载经过 SHA256 校验的公开提示和评分函数。
- 提示采用题目、按 A/B/C 等排列的选项及直接回答字母的指令；按照公开 RoboBrain HTTP adapter 附加 `<think></think><answer>`。
- 输入图片按公开 HTTP 工具的方式转为 RGB JPEG、quality=95，不额外缩放；模型采用 checkpoint 自带的图像处理配置。BF16、贪心解码、temperature=0、最多生成 4,096 tokens。
- ADE20K、COCO 分别计算准确率，先取两者平均得到 2D 分数；再与 Omni3D 的 3D 分数等权平均得到总分。保持上游逐级保留两位小数的规则，不能用全量题目简单正确率代替该总分。
- 原始响应、请求提示、输入图像哈希、来源分组、标签、错误及截断状态逐例保留。错误和截断不从分母剔除。服务退出时终止测试并保留部分证据，排障后的测试使用新目录。
- 论文没有公开该次运行的完整配置、精确代码 revision 和 RoboBrain2.5 专用 adapter。本复测记录上述实际设置，结果作为相同公开基准下的对照，不能宣称逐项配置已与论文完全一致。

复现命令（服务启动于另一终端）：

```bash
bash run-scnet.sh python scripts/prepare_cvbench.py
RUN_RESULTS_DIR="$PWD/results/scnet/publisher-runtime-c64-20261026" \
  MEM_FRAC=0.5 bash run-scnet.sh
# 服务就绪后，在另一终端执行：
bash run-scnet.sh python scripts/evaluate_cvbench.py \
  --runtime-dir results/scnet/publisher-runtime-c64-20261026 \
  --output results/scnet/publisher-cvbench-full-20261026 --workers 2
```

首次下载需要网络；所有数据与上游脚本只写入模型目录下的 `cache/`，代码仓库只提交来源、固定版本、哈希及评测代码和证据。

## 高分辨率输入修复

全量数据预跑发现确定性 BMM 的输出矩阵索引存在边界问题：输入 A/B 未超过 2³¹ 元素、输出 C 超过该数量时，批次偏移没有提升为 int64。补丁增加 `C_LARGE` 判断，其他数值计算方法不变。

修复后的框架 SHA256：`371f9816ae1614d944dce1616ee2e88a6d1b6dfed2ca660275ae28cb9785bb39`；原始源码和前版补丁哈希由重放程序校验。差异见 `patches/deterministic-bmm-large-output.patch`。

边界回归使用 B=129、M=4096、K=1、N=4096，共 2,164,260,864 个输出元素，末批次起始偏移为 2³¹。逐批检查全部输出的最小值及最大值与解析参考一致，通过；小矩阵 BF16/FP32 数值与批次一致性复测通过。证据写入 `results/scnet/publisher-runtime-c64-20261026/`。

首版性能矩阵对应旧补丁版本；没有将其冒充本次新补丁及 MEM_FRAC=0.5 下重新测得的性能。
