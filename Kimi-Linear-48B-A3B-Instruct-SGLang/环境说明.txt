Kimi-Linear-48B-A3B-Instruct —— 环境说明
==========================================

模型及权重版本
--------------
  model            : moonshotai/Kimi-Linear-48B-A3B-Instruct
  architecture     : Kimi Linear（KDA 线性注意力 + 全局 MLA，3:1 混合）
  total params     : 48B
  activated params : 3B
  dtype            : BF16
  权重存放         : 共享存储，通过本目录 weights/ 读取；启动脚本不下载、不复制

框架及版本
----------
  framework        : 镜像内 SGLang
  model class      : KimiLinearForCausalLM
  attention backend: triton（显式指定）
  parallelism      : TP4（TENSOR_PARALLEL_SIZE=4）
  served name      : kimi-linear-48b-a3b
  endpoint         : http://127.0.0.1:30148

运行参数
--------
  max_model_len         : 8192
  max_num_seqs          : 4
  gpu_memory_utilization: 0.80
  CUDA Graph            : 关闭
  CPU offload           : 0 GB

设备信息
--------
  device           : BW（海光 DCU / HCU）
  device count     : 4
  显存             : 每卡约 64 GiB

镜像
----
  镜像入口         : https://www.scnet.cn/ui/aihub/image/zack233/2116173177861849089
  镜像类型         : 专用 Notebook 镜像
  复验范围         : 同 Notebook 内两轮独立服务进程；未另建实例复验

执行范围
--------
  数据集           : 固定 GSM8K 200 题公开自评样本
  数据来源         : 与同批 MiMo-V2.6-Distill-Qwen-9B 共用同一份文件
  gsm8k sha256     : 03bd22060d201b82f3545a56dc89a01d300a5406d79e1d51529fdedceb698546

采样与评分配置
--------------
  few_shot         : 0
  temperature      : 0（greedy）
  top_p            : 1
  enable_thinking  : True
  max_tokens       : 4096
  workers（并发）   : 32
  GSM8K 评分       : 取最终 "####" 后的数值，Decimal 比较
  分母口径         : 全部样本；错误 / 截断 / 解析失败均计为错误，无随机回退

结果摘要
--------
  GSM8K            : 185/200 = 92.50%（截断 0、解析失败 0、请求错误 0）
  功能             : 两个独立服务进程各 6/6
  性能与复现       : 6 档（短/长提示 × 并发 1/2/4），两轮最大偏差 12.69%

与发布者成绩的关系
------------------
  发布者未公布本 Instruct 权重的 GSM8K 成绩。模型卡首页分数属 1.4T 实验模型，
  Base 权重成绩亦不适用，二者均已在 sources/accuracy-reference.json 的
  do_not_use 字段中排除。本报告数字用于确认适配未破坏模型能力，
  不宣称复现发布者成绩，也不作为及格线判定。

框架路线说明
------------
  同镜像 vLLM 0.25.1 路线可加载 TP4 权重，但聊天与原始补全接口均持续
  输出 token 0（"!"），关闭专家并行后不变；该路线未用于本报告任何结果。
  本报告全部结果来自 SGLang TP4 + Triton 注意力后端。

真实性与边界
------------
  本文件记录实际执行的参数与实测结果，未编造版本、成绩或运行数据。
  GSM8K 结果为零截断的完整结果，可作为适配后的能力自评。
