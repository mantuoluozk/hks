# AuK 适配与稳定性配置

固定 SGLang-Omni `428b73225f808f0d93669140983e90839c9aea0e`。四个平台模块的 `resolved_view` 导入通过模型局部兼容层回退到现有 SGLang 的真实 `overrides` 实现；共五文件改动，SHA 见 `sources/dtk-compat-files.json`。不替换全局 PyTorch / SGLang，不修改权重。

初始 BF16 DiT 在同 seed 重复时出现 PCM 差异，并在一次性能请求中产生 NaN / HTTP 500，历史记录见 `results/performance-20261028/`。正式配置采用编码器 BF16、DiT/VAE FP32、Math SDPA 与确定性算法，最大 batch=1。两独立服务各九项功能通过，七个有效音频用例的 PCM 哈希跨进程一致。

正式性能为两个独立服务各32次计时请求、6次预热。平均延迟与音频吞吐最大复跑偏差1.1583%。此配置以稳定运行与首版实测为目标，没有同负载完整成功的旧版基线，不宣称相对加速比。仅 HTTP 编辑可执行性经过检查，编辑语义质量未作评分。
