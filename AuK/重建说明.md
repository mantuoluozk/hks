# AuK 镜像与源码重建

提交镜像为 [SCNet AuK 镜像](https://www.scnet.cn/ui/aihub/image/zack233/2115345884192739329)，内置 `/opt/auk`。直接使用该镜像时无需重建；代码目录和权重放在共享存储，按 README 启动。

实际首版构建 Dockerfile、588文件清单及校验安装器保存在 `sources/image-build/`。镜像不包含权重或测试集。固定上游源码、局部兼容补丁和九个 wheel 的来源及 SHA 分别见 `sources/sglang-omni-runtime-files.json`、`sources/dtk-compat-files.json`、`sources/runtime-wheels.json`。

需要从基础镜像重建时，使用 Python3.10 / Linux x86_64 获取以下固定小型源码与 wheel；不升级全局推理栈：

```bash
git clone https://github.com/sgl-project/sglang-omni /tmp/auk-omni-source
git -C /tmp/auk-omni-source checkout 428b73225f808f0d93669140983e90839c9aea0e
python -m pip download --no-deps -r requirements-runtime.txt -d /tmp/auk-wheels
python scripts/rebuild_image_context.py --source-dir /tmp/auk-omni-source \
  --wheel-dir /tmp/auk-wheels --output /public/home/zack233/dockerFileTemp/auk-rebuild
```

新目录内的 `Dockerfile.auk` 以 `image.ac.com:5000/dcu/zack233/base/sglang-jupyter:0.5.18` 为基础。平台构建时传入这个新 Dockerfile；该基础地址需构建节点有访问权限。准备脚本按固定文件SHA验证所有输入，离线安装九个包到 `/opt/auk/site-packages`。新生成的构建目录包含当前报告配套脚本，不能冒充已经复验的首版590文件上下文；首版真实记录以保存的清单与镜像页为准。

精度评测另将 `requirements-eval.txt` 中四个固定包以 `pip install --no-deps --target runtime/eval-deps -r requirements-eval.txt` 安装到模型局部目录；Whisper与评测数据按 README 固定来源准备。
