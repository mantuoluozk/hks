# 强制对齐适配与首版基准

使用原生 vLLM token classification 实现及 BF16 权重，runner 为 pooling。通过 `hf_overrides.architectures` 选择已有的强制对齐模型实现；不修改权重、分类头参数或框架源码。

本版先采用 eager、最大运行序列 8、显存比例 0.35、上下文 8192；prefix cache 和多模态处理缓存关闭。文本拆分、时间戳标记与后处理采用固定发布者版本的原始处理器类。接口只验证 English / Chinese。

首版分别记录单条功能和批次大小 1/2/4/8 的两轮吞吐。初始化、音频读入、重采样与文本准备不计入引擎调用计时；`llm.encode` 内部的特征处理和模型推理仍包含在计时内。批量与串行输出差异按原始时间戳记录，不把差异当作 AAS 精度分数。

独立进程复跑用于复现检查，不作为优化提升。后续图执行、批处理或调度优化需另做同卡、同框架、同负载配对比较并保留首版结果。正式 AAS 精度等待匹配的标注和评分程序。

计数口径为四档 × 两轮 × 每轮64请求，共512；只报告第二轮，并保留第一轮数据。原始逐条记录中的 elapsed_seconds 复用所在批次的完整调用耗时，不作为独立逐请求延迟。
