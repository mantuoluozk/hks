# Qwen3-ForcedAligner 精度基线与口径

2026-10-26 查阅[发布者官方 README 的 Forced Alignment Benchmarks](https://github.com/QwenLM/Qwen3-ASR#evaluation)。指标为 AAS，单位 ms，越低越好。

| 发布者评测组 | 公开参考值 |
|---|---:|
| MFA-Labeled Raw，中文 | 33.1 ms |
| MFA-Labeled Raw，英文 | 37.5 ms |
| MFA-Labeled Raw，平均 | 42.9 ms |
| MFA-Labeled Concat-300s，平均 | 52.9 ms |
| Human-Labeled，平均 | 32.4 ms |

这些是不同评测组的公开分数，不能混用。重现 AAS 需要对应音频、给定文本、词/字边界标注、样本划分及一致的评分口径。不能用两个演示音频、时间戳非空、单调、范围合法或 ASR 转写一致来替代 AAS，也不能自行生成标注后直接对比上述数值。

当前先完成 BF16 原生 vLLM 功能与性能首版。正式精度等待赛事测评代码及匹配 GPU 基线，`official_accuracy_pass=null`。实际完成的工程检查单独记录，不冒充精度验收。
