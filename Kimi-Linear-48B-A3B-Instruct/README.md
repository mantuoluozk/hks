## 适配结论

模型已在海光 DCU（BW，4 卡，SGLang 张量并行 TP4）完成部署并可正常推理。功能、性能验证见 `results/validation-*`。

## 公开精度自评

本模型发布者**未公布** GSM8K / MMLU 成绩（论文 Table 9 仅给出 MMLU-Pro 72.7%，README 首页的 51.0 属 1.4T 实验模型，Base 权重 GSM8K 86.3 也不适用于本 Instruct 权重，详见 `sources/accuracy-reference.json` 的 `do_not_use` 字段）。因此本节数字为**适配后的自测参考值**，用于确认适配未破坏模型能力，不作为对发布者成绩的复现。

| 数据集 | 样本 | 正确 | 准确率 | 截断 | 解析失败 | 错误 |
|---|---|---:|---:|---:|---:|---:|
| **GSM8K** | 200 | **185** | **92.50%** | 0 | 0 | 0 |
| MMLU（未完成） | 96 | 70 | 72.92% | 19 | 18 | 0 |

### GSM8K 为有效结果

200 题全部完成，**零截断、零解析失败、零请求错误**，是最干净的一项结果，作为本模型的精度自评结论。

### MMLU 未完成，不作为精度结论

MMLU 在跑完 96/200 时按用户决定停止，原因是单题耗时过长（中位 227 秒，最长 595 秒）。此外 `max_tokens=4096` 下有 19 条（19.8%）输出被截断——该模型在 MMLU 上的推理链显著长于同批 Qwen 系模型，4096 预算不足。**72.92% 是在截断与未完整样本下的中间值，不构成有效精度结论，不对外引用。**

## 评测协议

- 数据：固定 200+200 公开自评样本，与同批 MiMo-V2.6-9B 使用同一份文件（SHA256 校验一致）
  - `gsm8k` sha256 `03bd22060d201b82f3545a56dc89a01d300a5406d79e1d51529fdedceb698546`
  - `mmlu` sha256 `84f929be5a22b7f7895961ef19f3842dc3d9a276a42b82c42a6fe95e1395682d`
- 采样：0-shot、greedy（temperature=0、top_p=1）、开启思考、max_tokens=4096、并发 32
- 评分：GSM8K 取最终 `####` 数值（Decimal 比较，容忍 `$`、千分位与加粗）；MMLU 取最终 `ANSWER: A/B/C/D`
- 分母：全部样本；错误、截断、解析失败均计为错误，不做随机回退

### 与同批 MiMo 的差异（如实记录）

| 参数 | 本模型 | MiMo-V2.6-9B |
|---|---|---|
| temperature / top_p | 0 / 1 | 0 / 1 |
| max_tokens | 4096 | 4096 |
| **并发** | **32** | **8** |

并发不影响 greedy 解码的判定结果，但本批实际并发与同批模型不一致，已在文档中注明，不宣称完全同协议。
